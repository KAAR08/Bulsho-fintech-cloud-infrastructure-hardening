# Company Profile
Bulsho Fintech is a hypothetical small startup based in Nairobi. They have developed a revolutionary API that allows rural shopkeepers to accept digital micro-payments. They are about to launch their MVP (Minimum Viable Product), but their lead developer just realized they have no formal security layers.

# The Problem
They are hosting their API on an Ubuntu server in Azure. Currently, the server is "naked"—it has a public IP, and the database is on the same machine. They are terrified of a data breach before they even launch.

# Mission
Your goal is to transform this "naked" server into a hardened, multi-layer defensive environment.
